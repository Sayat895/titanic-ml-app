# 🚢 Titanic ML Studio — Анализ данных и прогноз выживаемости

Интерактивное веб-приложение на **Python + Streamlit + Scikit-Learn** для разведочного анализа датасета «Титаник», конструирования признаков (Feature Engineering) и прогнозирования вероятности выживания пассажиров.

## Что умеет приложение
* **Feature Engineering:** автоматическое извлечение титулов (`Mr`, `Mrs`, `Miss`, `Master`, `Rare`), расчет `FamilySize`, `IsAlone` и флага наличия каюты `HasCabin`.
* **Сравнение 3 алгоритмов ML:** Random Forest, Gradient Boosting и Logistic Regression с настройкой гиперпараметров на лету.
* **Интерактивный EDA:** графики выживаемости по классу, полу, возрасту и социальному статусу на базе Plotly.
* **Пакетный прогноз:** загрузка любого CSV-файла (например, `test.csv` из Kaggle) и выгрузка готового файла с вероятностями спасения.
